# راهنمای استفاده از SubTrans Auto (مترجم خودکار زیرنویس)

به SubTrans Auto خوش آمدید! با این برنامه می‌توانید کل قسمت‌های یک فصل از یک سریال یا انیمه را تنها با یک کلیک به زیرنویس فارسی باکیفیت و بدون خراب شدن استایل‌ها و تگ‌ها ترجمه کنید.

---

## ۱. نصب و راه‌اندازی سریع

برای شروع نیازی به نصب دستی پکیج‌ها ندارید:
1. مطمئن شوید **پایتون (نسخه ۳.۱۱ یا جدیدتر)** روی ویندوز شما نصب است.
   - اگر نصب نیست، کلیدهای `Win + R` را بزنید، تایپ کنید `cmd` و اینتر بزنید، سپس دستور زیر را وارد کنید:
     ```bash
     winget install Python.Python.3.11
     ```
2. روی فایل **`START.bat`** دو بار کلیک کنید.
   - برنامه به صورت خودکار محیط مجازی می‌سازد، پیش‌نیازها را نصب می‌کند، سلامت سیستم را بررسی می‌کند و رابط کاربری را در مرورگر شما باز می‌کند.

---

## ۲. تنظیم گیت‌وی هوش مصنوعی (9Router / سایر ارائه‌دهنده‌ها)

این برنامه از تمام سرورهای سازگار با استاندارد OpenAI پشتیبانی می‌کند:
1. اگر از **9Router** استفاده می‌کنید، مطمئن شوید نرم‌افزار 9Router روشن است.
2. در تب تنظیمات برنامه (Settings):
   - **آدرس سرور (Base URL):** پیش‌فرض `http://127.0.0.1:20128/v1` است.
   - **کلید API:** اگر سرور شما به کلید نیاز دارد وارد کنید (در رابط کاربری ماسک می‌شود).
   - **مدل:** با زدن دکمه «دریافت مدل‌ها» یا وارد کردن نام مدل (مانند `gemini-2.5-flash` یا `deepseek-chat`) مدل دلخواهتان را مشخص کنید.
   - روی دکمه **تست اتصال** کلیک کنید تا از اتصال سالم مطمئن شوید.

---

## ۳. شروع اولین ترجمه

1. در بخش **ورودی (Input)**، آدرس پوشه حاوی ویدیوها یا فایل‌های زیرنویس را انتخاب کنید.
2. سیستم به صورت خودکار زیرنویس‌های داخل فایل‌های MKV یا MP4 را پیدا می‌کند.
3. در صورت تمایل، قبل از شروع دکمه **تخمین هزینه و زمان (Dry Run)** را بزنید تا تعداد خطوط و حجم درخواست‌ها را ببینید.
4. دکمه **شروع (Start)** را بزنید.

زیرنویس‌های ترجمه‌شده با پسوند `.fa.srt` یا `.fa.ass` مستقیماً کنار هر فایل ویدیویی ذخیره می‌شوند و فایل‌های اصلی شما به هیچ عنوان دستکاری یا حذف نخواهند شد.

---

## ۴. ادامه کار پس از توقف یا قطعی (Resume)

اگر اینترنت قطع شد، سهمیه API به پایان رسید یا دکمه Pause را زدید:
- پیشرفت هر خط به صورت لحظه‌ای در پایگاه‌داده ذخیره می‌شود.
- در اجرای بعدی، برنامه خطوطی که قبلاً ترجمه شده‌اند را به صورت خودکار رد می‌کند و حتی یک درخواست اضافی به هوش مصنوعی ارسال نمی‌کند.

---

## ۵. عیب‌یابی (Troubleshooting)

اگر با مشکلی مواجه شدید، می‌توانید در ترمینال دستور زیر را اجرا کنید تا وضعیت سلامت سیستم را بررسی کنید:
```bash
python -m subtrans doctor
```

- **خطای FFmpeg پیدا نشد:** دستور `winget install Gyan.FFmpeg` را در CMD اجرا کنید و کامپیوتر را ری‌استارت کنید.
- **خطای اتصال به سرور هوش مصنوعی:** مطمئن شوید 9Router یا سرور مدل محلی شما روشن است و پورت ۲۰۱۲۸ آزاد است. فیلترشکن‌ها و پراکسی‌ها برای آدرس‌های لوکال (`127.0.0.1`) توسط برنامه نادیده گرفته می‌شوند تا تداخلی رخ ندهد.
- **مشکل جابه‌جایی علائم در تلویزیون یا پلیر:** در تنظیمات، حالت **BiDi** را روی یکی از حالت‌های `rle` یا `rlm` بگذارید. با فایل آزمایشی `bidi_test.srt` می‌توانید بهترین نمایش را در تلویزیون خود انتخاب کنید.
